Joy-Con & Controller Guide

Supports Handheld Mode, Dual Joy-Con (Paired L+R), and Nintendo Switch Pro Controller.

Joy-Con Tips:
• Pair both Joy-Cons as Dual Joy-Con (not single sideways) via Switch Home Menu → Controllers → Change Grip/Order before launching.
• On Eden Emulator, set Player 1 to Pro Controller or Dual Joy-Con.
• Right Stick shifter support is planned for a future update.

How to Install

Clean SD card folder layout ready to extract directly to your Switch.

  1. Download Super3DXPlus-NX_v1.0.1.zip from the GitHub Releases page.
  2. Extract the archive directly to the root of your SD card (sdmc:/).
  3. Copy your own legally obtained game assets into sdmc:/switch/Super3DXPlus/data/.
  4. Launch via Title Takeover (hold R on any game) or an NSP Forwarder. Applet Mode is not supported.

Important Notices

  • No Copyrighted Assets: Release includes the .nro binary only. No ROMs or data/ files are distributed.
  • Windows Defender False Positive: Unsigned homebrew archives can trigger Windows Security. Add your extraction folder to Exclusions if blocked.
  • Known Issue: Minor visual glitch in 10 Outrun mode (missing boundary lines / brief blue flash). Does not crash.
