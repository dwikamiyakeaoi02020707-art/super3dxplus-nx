Controller & Touch Tips:
• Pair both Joy-Cons as Dual Joy-Con (not single sideways) via Switch Home Menu → Controllers → Change Grip/Order before launching.
• Arcade menus can be tapped directly using the Switch Touchscreen.
• PS5 DualSense & Xbox 360 work via Mission Control on Switch CFW or directly on Eden Emulator.

How to Install

Clean SD card folder layout ready to extract directly to your Switch.

  1. Download the latest release ZIP containing super3dx+nx.nro from GitHub Releases.
  2. Place the homebrew at sdmc:/switch/super3dx+nx/super3dx+nx.nro (filename stays super3dx+nx.nro for compatibility).
  3. Copy your own legally obtained converted game assets into sdmc:/switch/super3dx+nx/data/.
  4. Launch via Title Takeover (hold R on any game) or an NSP Forwarder. Applet Mode is not supported.

Important Notices

  • Code-Only Release: Downloads include the .nro binary only. No ROMs, dumps, or data/ files are distributed.
  • Auto-Log Troubleshooting: If you encounter a black screen or crash, check sdmc:/switch/super3dx+nx/save/log.txt.
  • Windows Defender False Positive: Unsigned homebrew archives can trigger Windows Security. Add your extraction folder to Exclusions if blocked.

Version History & Known Bugs

Full release changelog, fixes, and tracked bugs for every NSwitch3DX+ build.

v1.0.2 Early Access / WIP NSwitch3DX+ Rebrand
2026

What's New

  • Official rebrand from Super3DX+ NX to NSwitch3DX+ (binary stays super3dx+nx.nro).
  • Added Touchscreen menu navigation & Online / LAN Versus support.
  • Added automatic diagnostic logging to save/log.txt.
  • Export (English) version supported; Japan (JPN) version in testing.

Known Bugs

  • Save-Data Overwrite Bug (Fixing): garage1: could not move the new file in on FAT32/Horizon FS & Eden causes new cars/HP upgrades to revert after restart. Fix in progress.
  • NAT / UPnP: nat: ssdp found nothing may appear on emulators or strict routers; manual port forwarding is required for Online Versus.
  • 10 Outrun Visual Glitch: Boundary lines may disappear with a brief blue flash (does not crash).
v1.0.1 Stable Hotfix
2026

What's New

  • Fixed garage & ranking save-data persistence on Horizon FS / FAT32 and Eden Emulator.
  • Stable 60 FPS native gameplay on Switch CFW without overclocking.

Known Bugs

  • 10 Outrun Mode: Minor rendering glitch (missing boundary lines / brief blue flash near the 10th rival). No crash.
  • Applet Mode: Launching from Album is not supported (requires Title Takeover or NSP Forwarder).
v1.0.0 Initial Port
2026

What's New

  • First unofficial Nintendo Switch homebrew port (devkitPro, libnx, SDL2, OpenGL ES 3.2).
  • Handheld, Dual Joy-Con, and Pro Controller support.

Known Bugs

  • Save-Data Issue: rename() overwrite failed on FAT32/Switch (fixed in v1.0.1).
  • No touchscreen menu or Online/LAN Versus support yet.
